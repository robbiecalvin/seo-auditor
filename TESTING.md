# Testing SEO Auditor

Run `pip-audit -r requirements.txt` to inspect pinned dependencies. A clean scan does not establish application correctness. For functional verification, use a controlled local fixture site containing redirects, broken links, missing metadata, duplicate titles and missing image alt text. Compare CSV and HTML output against expected findings. Respect authorization and crawl limits. Record actual commands, revision and results; fixture coverage described here is proposed, not an existing automated suite.
